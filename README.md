# ✅ TaskFlow – Advanced To-Do / Task Manager

A fully responsive task management web application built with **HTML, CSS, Bootstrap 5 & JavaScript** using **LocalStorage** for persistent data.

## 🚀 How to Run
> Open `index.html` in any browser — No internet required! (Works fully offline)

## 📋 Description
TaskFlow is a feature-rich task manager where users can add, edit, delete, and manage tasks with priority levels, status tracking, categories, due dates, and persistent local storage.

## ✨ Features
- ➕ Add, ✏️ Edit, 🗑️ Delete tasks
- ✅ Mark tasks as Complete / Incomplete
- 🔴🟡🟢 Priority levels — High, Medium, Low
- 📊 Status tracking — To Do, In Progress, Completed
- 🗂️ Categories — Work, Personal, Shopping, Health
- 📅 Due date with Overdue detection
- 🔍 Search tasks by title, description, category
- 🔃 Sort by Newest, Oldest, Priority, Due Date, A-Z
- 📈 Progress bar & Stats dashboard
- 🏷️ Sidebar filters by status & category
- 🧹 Clear all completed tasks
- 📥 Export tasks as CSV file
- 💾 LocalStorage — data persists on refresh
- 📱 Fully Responsive — Mobile, Tablet & Desktop
- 🌙 Dark professional UI
